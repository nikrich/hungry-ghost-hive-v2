| # | Issue | Severity |

| 1 | Drawers land in ChromaDB only (visible via MCP) but NOT in `<workspace>/.hive/memory/wings/hive/rooms/*` as `.md` files. This means `hive status` (which reads the on-disk wings tree) still shows zero counts. The likely cause: claude is using the user's global mempalace gateway via `~/.claude.json`, not the workspace-local `MEMPALACE_ROOT=/tmp/hive-verify-ws/.hive/memory` from `.claude/mcp.json`. Suspect MCP-server precedence: user-global wins over workspace-local. | MEDIUM — drawers exist; just routed to the wrong instance |

| 4 | Worker was SIGKILL'd by `hive stop` while still running (PID 31151 was alive when I stopped). Stop cascade works but loses worker-in-flight. A graceful drain-then-stop mode might be useful eventually. | LOW |
