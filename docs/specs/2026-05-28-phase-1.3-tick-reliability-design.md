# Phase 1.3 — Tick Reliability + `hive status` Fix

**Status:** Draft — pending implementation plan
**Date:** 2026-05-28
**Predecessors:** [Phase 1.2 spec](2026-05-28-phase-1.2-workspace-local-memory-design.md), [Phase 1.2 verification runbook](../plans/2026-05-28-phase-1.2-verification-runbook.md)

## 1. Summary

Phase 1.2 verification surfaced three concrete issues that blocked the happy-path tick from completing:

1. **The manager process hung for the full 5-min watchdog budget** without writing any output to `manager.log`. Session log analysis showed the manager spent its time on exploratory Bash (looking for skills, listing directories) and on per-Bash-tool overhead from the user's globally-configured plugin hooks (`pretooluse.py`, `posttooluse.py`, `on-post-tool-use.sh`).
2. **`manager.log` was empty after SIGKILL** because claude buffers stdout when not connected to a TTY; the buffered content is lost when SIGKILL preempts the final flush.
3. **`hive status` errored with `MEMPALACE_ROOT environment variable not set`** because the Go code in `cmd/hive/status_cmd.go` still uses the Phase 0/1.1 env-var path; it never learned about the new workspace-local memory location at `<workspace>/.hive/memory/wings/hive/`.

Phase 1.3 addresses all three with minimal-LOC, high-confidence fixes:

1. Spawn manager (and skill-instructed workers) with `claude --bare` to skip user-side hooks and other per-tool overhead. Bump the watchdog timeout default from 5min → 8min as a safety margin. Add a two-bullet imperative to the manager skill against exploratory behavior.
2. The watchdog reads child stdout/stderr through a Go `bufio.Scanner` and writes each line to `manager.log` as it arrives — bypasses claude's stdout buffering and survives SIGKILL.
3. Add `paths.WorkspaceWingDir(workspaceRoot)`. Update `cmd/hive/status_cmd.go` to use it. Drop the `MempalaceRoot()` + `WingDir()` lookups from the status path.

Total: ~50 LOC of Go + ~3 lines of skill markdown.

## 2. Goals & Non-Goals

### Goals

- Manager ticks reliably complete inside the watchdog budget; no more empty-log SIGKILL mystery.
- `manager.log` survives SIGKILL with all output emitted up to the kill point.
- `hive status` works against a Phase 1.2-initialized workspace.
- Verification re-run produces the full happy-path tick (drawer writes + worker spawn + worker completes its story).

### Non-goals

- Embedding mempalace in the binary
- Changing the skill discovery model (workspace `.claude/skills/` is auto-loaded — verified working in P1.2)
- Removing the dead `discoverMempalaceMCP` helper (still defer)
- Adding more roles (still Phase 2)
- Switching to `--system-prompt-file` inlining (held as Phase 1.4 contingency if `--bare` alone doesn't fix the hang)

### Code shapes

**Watchdog spawn change:**

```go
cmd := exec.Command(
    opts.ClaudeBinary,
    "--bare",
    "--print",
    "--permission-mode", "acceptEdits",
    opts.ManagerPrompt,
)
cmd.Dir = opts.WorkspaceRoot

stdoutPipe, err := cmd.StdoutPipe()
if err != nil {
    return err
}
cmd.Stderr = cmd.Stdout  // merge stderr into stdout

cmd.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}

if err := cmd.Start(); err != nil {
    return fmt.Errorf("start manager: %w", err)
}

// Stream child output to manager.log line-by-line so partial output
// survives SIGKILL.
go func() {
    scanner := bufio.NewScanner(stdoutPipe)
    scanner.Buffer(make([]byte, 64*1024), 1024*1024) // allow up to 1 MiB lines
    for scanner.Scan() {
        _, _ = fmt.Fprintln(logFile, scanner.Text())
    }
}()
```

**`paths.WorkspaceWingDir`:**

```go
// WorkspaceWingDir returns <workspaceRoot>/.hive/memory/wings/hive.
// Phase 1.2: each workspace has a single fixed wing named "hive".
func WorkspaceWingDir(workspaceRoot string) string {
    return filepath.Join(workspaceRoot, ".hive", "memory", "wings", "hive")
}
```

**`hive status` rewrite:** drop the slug lookup and env-var path; use `paths.WorkspaceWingDir(ws)` directly; pass to `cli.RenderStatus(out, wingRoot)`.

**Manager skill addition (2 new bullets at the top of the MUST/MUST NOT block):**

## 7. Open risks

| Risk | Mitigation |
|---|---|
| `--bare` disables hooks that hive depends on (e.g., the user's mempalace SessionStart hook) | Mempalace doesn't need session hooks for hive's purposes — the mempalace MCP gateway is launched per-session via mcp.json regardless. If verification reveals a needed hook, we can selectively re-enable via the `--settings` flag (Phase 1.4) |
| `cmd.Stderr = cmd.Stdout` merges streams but timing can still interleave oddly with the bufio scanner | At the granularity of "lines per second" this is fine. The scanner reads from the merged pipe; the only artifact is line-level ordering (a stderr line could land between two stdout lines that were written consecutively). Acceptable for a log file. |
| Watchdog goroutine leaks if the pipe doesn't close cleanly | `cmd.StdoutPipe()` is closed by `cmd.Wait()` per the stdlib contract. Goroutine exits on EOF. No leak. |
| Manager skill text addition doesn't actually stop exploration (model interprets it loosely, as in Phase 1.1) | We accept this risk because `--bare` is the main lever. The skill text is backstop. If verification shows exploration despite both, escalate to `--system-prompt-file`. |
| 8-min timeout is still too tight | Configurable per-workspace via `.hive/config.yaml`; verification will tell us if 8min is enough |
